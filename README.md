# 🥽 CORE-MR — Realidade Mista 3DOF + Controle por Mãos
Projeto Unity para Android: interface própria, menu 3D, rastreamento manual e giroscópio.

✅ Características:
- Rastreamento de mãos para navegação
- Sistema de câmera 3DOF (segue orientação)
- Menu independente flutuante
- Estrutura limpa e pronta para build

📂 Estrutura:
- `Assets/Scripts/` → Código principal
- `Assets/Scenes/` → Cena principal
- `Packages/` & `ProjectSettings/` → Configurações Unity
